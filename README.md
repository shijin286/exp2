# Ex. No. 2 – Responsive E Commerce Product Catalog

**BookNest** is a responsive online book store catalog built with Flutter.

- The layout changes with screen width: mobile (< 600), tablet (600–1023) and desktop (≥ 1024)
- Genre chips on mobile and tablet, and a genre sidebar with book counts on desktop
- The number of grid columns (2–5) is calculated from the available width
- Search by title or author, sort by popularity, price or rating
- Grid/list toggle, and a book details bottom sheet with Add to Cart

## Run

```
flutter pub get
flutter run -d chrome
```
